# PRD: 오늘의 할일 웹페이지

| 항목 | 내용 |
| --- | --- |
| 문서 상태 | 초안 (v0.1) |
| 작성일 | 2026-11-02 |
| 범위 | 설계까지 (구현 미포함) |

---

## 1. 개요

### 1.1 배경
할일 앱은 대부분 프로젝트, 태그, 마감일 같은 기능이 많아 "오늘 무엇을 해야 하는가"에 집중하기 어렵다. 할일이 쌓이기만 하고 정리되지 않아 사용을 중단하는 경우도 많다.

### 1.2 제품 정의
**오늘 할 일만 다루는, 설치와 가입 없이 바로 쓰는 1인용 웹페이지.** 페이지를 열면 오늘의 할일이 바로 보이고, 입력 한 번으로 추가하며, 클릭 한 번으로 완료한다.

### 1.3 목표
- 페이지를 연 뒤 첫 할일을 추가하기까지 5초 이내
- 새로고침하거나 브라우저를 다시 열어도 데이터 유지
- 서버, 계정, 빌드 도구 없이 동작

### 1.4 비목표 (이번 버전에서 하지 않음)
- 회원가입, 로그인, 기기 간 동기화
- 여러 사용자 간 공유, 협업
- 프로젝트, 태그, 우선순위, 반복 할일, 알림
- 먼 미래 날짜의 일정 관리 (캘린더 앱의 영역)

## 2. 대상 사용자와 시나리오

**대상 사용자:** 하루 업무나 개인 일과를 간단히 정리하려는 개인. PC 브라우저를 주로 쓰고 모바일로도 가끔 확인한다.

| # | 시나리오 | 기대 동작 |
| --- | --- | --- |
| S1 | 아침에 페이지를 열어 오늘 할 일을 적는다 | 입력창에 바로 커서가 있고, Enter로 연속 입력할 수 있다 |
| S2 | 일을 끝내고 체크한다 | 즉시 완료 표시되고 진행률이 올라간다 |
| S3 | 어제 못 끝낸 일이 남아 있다 | 오늘 화면에서 안내되고, 오늘로 옮기거나 삭제할 수 있다 |
| S4 | 오타를 고치거나 필요 없는 일을 지운다 | 그 자리에서 수정하고, 삭제는 실행 취소할 수 있다 |

## 3. 기능 요구사항

우선순위: **P0** 첫 버전 필수 / **P1** 첫 버전 포함 권장 / **P2** 이후 검토

### 3.1 할일 관리

| ID | 기능 | 우선순위 | 상세 및 수용 기준 |
| --- | --- | --- | --- |
| F-01 | 할일 추가 | P0 | Enter 또는 추가 버튼으로 등록. 앞뒤 공백 제거 후 빈 값은 등록하지 않음. 최대 200자. 등록 후 입력창을 비우고 포커스 유지 |
| F-02 | 완료 토글 | P0 | 체크박스 클릭 또는 Space로 완료/미완료 전환. 완료 항목은 취소선과 흐린 색으로 표시 |
| F-03 | 할일 수정 | P0 | 더블클릭 또는 수정 버튼으로 인라인 편집. Enter 저장, Esc 취소. 빈 값으로 저장하면 기존 값 유지 |
| F-04 | 할일 삭제 | P0 | 확인 창 없이 즉시 삭제하고, 5초 동안 "실행 취소" 토스트 표시 |
| F-05 | 데이터 유지 | P0 | 모든 변경을 즉시 저장. 새로고침, 브라우저 재시작 후에도 유지 |
| F-06 | 순서 변경 | P2 | 드래그 앤 드롭으로 순서 변경 |

### 3.2 오늘 화면

| ID | 기능 | 우선순위 | 상세 및 수용 기준 |
| --- | --- | --- | --- |
| F-10 | 오늘 날짜 표시 | P0 | `2026년 11월 2일 월요일` 형식으로 헤더에 표시 |
| F-11 | 진행률 표시 | P0 | `3 / 5 완료`와 진행 막대. 할일이 없으면 숨김 |
| F-12 | 정렬 | P0 | 미완료 항목이 위, 완료 항목이 아래. 각 그룹 안에서는 등록 순 |
| F-13 | 빈 상태 | P0 | 할일이 없을 때 안내 문구 표시 (예: "오늘 할 일을 적어보세요") |
| F-14 | 날짜 전환 처리 | P0 | 자정을 넘겨 페이지를 열어 둔 경우, 다음 포커스 시점에 새 날짜로 화면 갱신 |

### 3.3 미완료 이월

| ID | 기능 | 우선순위 | 상세 및 수용 기준 |
| --- | --- | --- | --- |
| F-20 | 지난 할일 안내 | P1 | 오늘 이전 날짜의 미완료 항목이 있으면 목록 상단에 "지난 할일 N개" 영역 표시 |
| F-21 | 이월 처리 | P1 | 항목별 또는 전체를 "오늘로 가져오기" / "삭제" 가능. 사용자가 처리하기 전에는 자동으로 옮기지 않음 |

| ID | 기능 | 우선순위 | 상세 및 수용 기준 |
| --- | --- | --- | --- |
| F-30 | 완료 항목 일괄 삭제 | P1 | "완료 항목 지우기" 버튼. 실행 취소 토스트 제공 |

## 4. 화면 설계

단일 페이지이며 라우팅은 없다.

```
┌────────────────────────────────────────┐
│  오늘의 할일                           │
│  2026년 11월 2일 월요일                │
│  ████████████░░░░░░░░  3 / 5 완료      │
├────────────────────────────────────────┤
│  [ 할 일을 입력하세요...       ] [추가]│
├────────────────────────────────────────┤
│  ⚠ 지난 할일 2개          [모두 가져오기]│  ← 있을 때만
│    ☐ 보고서 초안 작성    [가져오기][×] │
│    ☐ 회의록 정리         [가져오기][×] │
├────────────────────────────────────────┤
│  ☐ 메일 회신                     [✎][×]│
│  ☐ 장보기                        [✎][×]│
│  ☑ 운동하기 (취소선)             [✎][×]│
├────────────────────────────────────────┤
│                    [완료 항목 지우기]  │
└────────────────────────────────────────┘
          ┌───────────────────────────┐
          │ 삭제했습니다.  [실행 취소] │  ← 토스트, 5초
          └───────────────────────────┘
```

### 레이아웃
- 본문은 가운데 정렬, 최대 너비 600px
- 모바일(600px 미만)은 좌우 여백 16px, 터치 영역 최소 44×44px
- 수정/삭제 버튼은 항상 표시 (호버 전용으로 숨기면 터치 기기에서 쓸 수 없음)

### 컴포넌트 구성

| 컴포넌트 | 역할 |
| --- | --- |
| Header | 제목, 날짜, 진행률 |
| TodoInput | 입력창, 추가 버튼 |
| OverdueSection | 지난 미완료 항목과 이월 동작 |
| TodoList / TodoItem | 오늘 목록, 항목별 체크, 수정, 삭제 |
| ClearCompleted | 완료 항목 일괄 삭제 |
| Toast | 실행 취소 안내 |

## 5. 기술 설계

### 5.1 기술 스택

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 프론트엔드 | 순수 HTML, CSS, JavaScript | 화면이 하나이고 상태가 단순해 프레임워크가 필요 없음. 빌드 없이 파일을 바로 열 수 있음 |
| 저장소 | `localStorage` | 서버 없이 데이터 유지. 할일 규모에 용량이 충분함 |
| 배포 | 정적 파일 (로컬 실행, 필요 시 GitHub Pages 등) | 별도 서버 불필요 |

### 5.2 파일 구조 (예정)

```
todolist/
├── prd.md        이 문서
├── index.html    마크업
├── style.css     스타일, 라이트/다크 테마
└── app.js        상태 관리, 렌더링, 저장
```

### 5.3 데이터 모델

```js
// localStorage 키: "todolist.v1"
{
  "version": 1,
  "todos": [
    {
      "id": "b3f1c2e4-...",            // crypto.randomUUID()
      "text": "메일 회신",             // 1~200자
      "date": "2026-11-02",            // 할일이 속한 날짜 (로컬 시간 기준)
      "completed": false,
      "createdAt": "2026-11-02T09:12:00.000Z",
      "completedAt": null              // 완료 시 ISO 시각
    }
  ]
}
```

- `date`는 UTC로 변환하지 않고 사용자 **로컬 날짜**로 저장한다. `toISOString()`을 쓰면 한국 시간 오전 9시 이전에 전날 날짜가 되는 문제가 있다.
- 키에 버전을 포함해 이후 구조가 바뀌어도 마이그레이션할 수 있게 한다.

### 5.4 상태 흐름

단방향으로 처리한다. 사용자 동작마다 전체 흐름을 한 번 실행한다.

```
사용자 동작 → 상태 변경 → localStorage 저장 → 화면 다시 그리기
```

| 동작 함수 | 설명 |
| --- | --- |
| `addTodo(text)` | 오늘 날짜로 항목 추가 |
| `toggleTodo(id)` | 완료 여부 전환, `completedAt` 갱신 |
| `updateTodo(id, text)` | 내용 수정 |
| `deleteTodo(id)` | 삭제 후 실행 취소용으로 항목을 임시 보관 |
| `undoDelete()` | 임시 보관한 항목 복원 |
| `carryOver(id)` | 지난 항목의 `date`를 오늘로 변경 |
| `clearCompleted()` | 오늘의 완료 항목 일괄 삭제 |

### 5.5 조회 규칙
- 오늘 목록: `date === 오늘`
- 지난 할일: `date < 오늘` 이고 `completed === false`
- 지난 날짜의 완료 항목은 화면에 표시하지 않고 보관한다. (F-32 지난 기록 보기에 대비)

## 6. 예외 처리

| 상황 | 처리 |
| --- | --- |
| `localStorage` 사용 불가 (시크릿 모드, 차단 등) | 메모리로 동작하고 "이 브라우저에서는 저장되지 않습니다" 배너 표시 |
| 저장 용량 초과 | 오류 배너 표시, 완료 항목 삭제 안내 |
| 저장 데이터 손상 (JSON 파싱 실패) | 앱이 멈추지 않도록 빈 목록으로 시작하고, 원본은 `todolist.v1.backup` 키에 보존 |
| 여러 탭 동시 사용 | `storage` 이벤트로 다른 탭의 변경을 감지해 화면 갱신 |
| 사용자 입력에 HTML 포함 | `textContent`로만 출력해 스크립트 삽입 방지 (`innerHTML` 사용 금지) |

## 7. 비기능 요구사항

| 영역 | 요구사항 |
| --- | --- |
| 성능 | 첫 화면 표시 1초 이내, 동작 반응 100ms 이내 (할일 500개 기준) |
| 접근성 | 키보드만으로 모든 기능 사용 가능, 체크박스와 아이콘 버튼에 레이블 제공, 색상 대비 WCAG AA 충족 |
| 호환성 | Chrome, Edge, Safari, Firefox 최신 2개 버전 |
| 개인정보 | 데이터는 사용자의 브라우저에만 저장하며 외부로 전송하지 않음. 외부 추적 스크립트 없음 |
| 언어 | 한국어 UI (`lang="ko"`) |

## 8. 성공 기준

서버와 분석 도구가 없으므로 수치 측정 대신 아래 체크리스트로 완료를 판단한다.

- [ ] P0 기능의 수용 기준을 모두 통과
- [ ] 새로고침, 브라우저 재시작 후 데이터 유지
- [ ] 자정 전후 날짜 전환과 미완료 이월이 정상 동작
- [ ] 마우스 없이 추가, 완료, 수정, 삭제 가능
- [ ] 375px 모바일 폭에서 가로 스크롤 없음
- [ ] 라이트/다크 모드 모두에서 가독성 확보

## 10. 확인이 필요한 사항

아래는 기본값을 정해 작성했으며, 다르게 원하시면 구현 전에 수정한다.

| 항목 | 현재 기본값 | 대안 |
| --- | --- | --- |
| 미완료 이월 방식 | 사용자가 직접 가져오기 | 다음 날 자동 이월 |
| 데이터 저장 위치 | 브라우저 `localStorage` | 서버 DB와 로그인 (기기 간 동기화 가능, 범위 크게 증가) |
| 기술 스택 | 순수 HTML/CSS/JS | React 등 프레임워크 (기능 확장 시 유리) |
| 지난 완료 기록 | 보관만 하고 화면 미표시 | 첫 버전부터 기록 보기 제공 |

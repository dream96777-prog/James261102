## 1. 개요

Python과 HTML5 앱 개발을 주력으로 하는 개발자의 역량과 작업물을 소개하는 개인 프로필 웹사이트를 만든다. 방문자가 개발자의 전문 분야와 프로젝트를 빠르게 파악하고, 이메일로 바로 연락할 수 있도록 하는 것이 핵심이다.

## 2. 목표

- 주력 분야(Python, HTML5 앱 개발)를 첫 화면에서 바로 전달한다.
- 프로젝트 사례를 통해 실제 개발 역량을 보여 준다.
- 방문자가 클릭 한 번으로 이메일 연락을 시작할 수 있게 한다.
- PC와 모바일 어디서나 빠르고 편하게 볼 수 있게 한다.

### 범위에서 제외

- 회원가입, 로그인 등 사용자 계정 기능
- 관리자 페이지 및 CMS
- 블로그, 댓글 기능
- 다국어 지원 (v1 기준 한국어만 제공)

## 3. 대상 사용자

| 사용자 | 방문 목적 | 주로 확인하는 정보 |
|--------|-----------|--------------------|
| 채용 담당자 | 채용 후보 검토 | 보유 기술, 경력, 프로젝트 |
| 프로젝트 의뢰인 | 외주·협업 개발자 탐색 | 개발 가능 분야, 작업 사례, 연락처 |
| 동료 개발자 | 협업·교류 | 기술 스택, 프로젝트 상세 |

## 4. 주요 사용자 시나리오

1. 채용 담당자가 첫 화면에서 주력 분야를 확인하고, 프로젝트를 살펴본 뒤 이메일로 연락한다.
2. 의뢰인이 모바일로 접속해 비슷한 작업 사례를 찾고, 이메일 버튼으로 문의한다.
3. 동료 개발자가 기술 스택 섹션과 프로젝트 소스 링크를 확인한다.

## 8. 기술 구성 (제안)

- **프런트엔드:** HTML5, CSS3, 바닐라 JavaScript
- **백엔드:** 없음 (정적 사이트)
- **배포:** GitHub Pages
- **콘텐츠 관리:** 프로젝트 정보를 JSON 파일로 분리해 코드 수정을 최소화

정적 사이트는 서버 운영 비용이 들지 않고 구조가 단순하며, HTML5 개발 역량을 그대로 보여 줄 수 있다.
